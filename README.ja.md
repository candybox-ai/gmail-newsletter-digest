# 購読メール精選

[简体中文](README.md) | [English](README.en.md) | 日本語

Gmail の購読メールから、朝刊・夕刊として読む価値のあるダイジェストをまとめます。一件ずつ開かなくても、重要な情報を逃しにくくなります。

ローカルファイルの読み書きとコマンド実行ができる AI Agent（Claude Code、Codex、Cursor、Grok Bot など）向けです。

## 対象ユーザー

受信トレイに大量の newsletter があり、すべてを読む時間がない人向けです。

## インストール

### 方法 1：Agent に依頼する（GitHub から skill をインストールできる場合）

```text
gmail-newsletter-digest をインストールしてください：https://github.com/candybox-ai/gmail-newsletter-digest
```

この方法に対応していない場合は、方法 2 を使ってください。

### 方法 2：コマンドライン

Node.js が必要です：

```bash
npx skills add candybox-ai/gmail-newsletter-digest
```

または、リポジトリを**お使いのツールが実際に参照する skills ディレクトリ**にクローンします。Claude Code では次が一般的です。

```bash
git clone https://github.com/candybox-ai/gmail-newsletter-digest.git ~/.claude/skills/gmail-newsletter-digest
```

Cursor、Codex、Grok Bot などは、各ドキュメントの skill / workflow パスを確認してから、そのディレクトリへクローンしてください。

インストール後、そのディレクトリに `SKILL.md` があること、および Agent の skill 一覧に表示されること（またはツールの手順で skill を再読み込みすること）を確認してください。

## 起動方法

インストール後は、Agent に例えば次のように話しかけます。

- メール購読から今日の朝刊ダイジェストを作って
- 夕刊ダイジェストを英語で作り、普段受け取るメールアドレスに送って
- まず Gmail を接続して、必読の購読リストを一緒に選んで
- 技術的な詳細を多めに説明し、重要情報はすべて残して（任意の表示設定）

## クイックスタート

初回は Setup を順番に完了してください（各ステップを確認してから次へ進みます）。

1. **Gmail を接続** — 指定した Gmail アカウントから購読メールを読む権限を付与
2. **購読範囲を確認** — 最近のメールから newsletter を選び、低頻度の購読も追加して最終リストを確認
3. **生成時刻と本文言語を設定** — 時刻・タイムゾーンと言語を確認。検証済みの本文言語は英語と中国語
4. **配信方法を設定** — 既定は会話内で渡す。送信先メールアドレスも指定できる

会話内で一度だけ生成する場合：ステップ 1–2 を完了し、本文言語を決めれば足ります。定期生成とメール配信は後から設定できます。

読者プロファイルは不要です。任意の設定は順序と詳しさだけに影響します。各メールの情報点を整理してから統合し、収録漏れを確認します。重点解説は最大 3 件、残りの重要情報は件数制限のない重要簡訊に収録します。公開リンクがなくても取得済みメールに根拠があればアクセス制限を明記して要約を残します。対象は確認した購読と期間内です。形式検証だけで無漏れを保証するものではありません。

## 依存関係

- **Gmail 権限（読み取り必須、送信は任意）**：指定アカウントの購読メールを読む。メール配信を有効にする場合のみ送信権限も必要
- 生成時刻は Setup で設定したタイムゾーンに従う
- **Python 3** 標準ライブラリ

## プライバシー

購読範囲、任意の表示設定、言語、送信先は、**Agent が動作している環境**に保存されます。このリポジトリ自体はそれらのデータを収集しません。

この skill は購読メールを読み取り、メール配信を有効にした場合にのみ完成したダイジェストを送信します。転送・削除・メールボックス内の既存メールの変更は行いません。
